# 实验选课助手（油猴版）

与 Chrome 扩展版（`../extension/`）功能一致的单文件 Tampermonkey 脚本，扩展版保留可用，两者选其一安装即可（都装会出现两层面板，样式互不冲突但不建议）。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展（Edge/Chrome 均可）
2. 点击 Tampermonkey 图标 → 「添加新脚本」，清空默认内容
3. 粘贴 `experiment-helper.user.js` 的全部内容，Ctrl+S 保存
   - 或者直接把 `.user.js` 文件拖进浏览器窗口，Tampermonkey 会弹出安装页
4. 打开实验列表页 `https://wlsy.webvpn.sau.edu.cn/lab2026/index.php?controller=student&action=experimentList`，表格上方出现「实验选课助手（油猴版）」面板即安装成功

## 功能

- 关键字搜索（实验名 / 教师 / 地点）
- 星期、场次点选筛选（chip 标签如「第2场 10:20」，悬停看完整时段）；仅看可约 / 隐藏已满 / 隐藏冲突场次
- 剩余人数排序；筛选条件自动记忆（刷新后保留）
- 节次码人话徽标：`3-1-2` → 「第3周 周一 第2场 10:20–11:50」（按官方实验上课时间，非理论节次）
- 课表冲突检测：按**真实时间重叠**判定（实验用官方场次表，课程用12节理论课表），重叠≥10分钟才标红并注明冲突课程名
- 课表设置：点面板右上角「课表设置」打开页面内弹层
  - 粘贴课表 PDF 文字自动解析（解析后补选星期）
  - 手动周网格勾选
  - 条目增删改、导入/导出 JSON、一键清空
- Tampermonkey 菜单里有「打开课表设置」入口（任何匹配页面可用）
- 「我的实验」页也自动加节次人话徽标

## 实验时间表与冲突检测

实验中心官方上课时间与理论课节次**不完全对应**（尤其晚场），详见 [extension/README.md](../extension/README.md#实验时间表与冲突检测) 的完整时间表。核心差异：

- 实验第5场 17:45–19:15 vs 理论晚9节起 18:30–22:00（差 45 分钟）
- 4学时晚场只有一场 17:45–20:45
- 粘贴课表含晚9-10节→与第5场重叠→冲突；11-12节→不重叠→不冲突

## 数据存储

- 优先存 Tampermonkey 的 `GM_getValue/GM_setValue`（跨页面持久，不清缓存不丢）
- 若脚本管理器不支持 GM API，自动降级为页面 `localStorage`
- 数据与 Chrome 扩展版互不相通；如需迁移，在一边「导出 JSON」，另一边「导入 JSON」即可

## 安全约束

只读解析与界面增强，**绝不自动提交任何预约请求**，预约仍需手动点击。
