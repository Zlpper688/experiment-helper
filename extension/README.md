# 实验选课助手（浏览器插件）

为开放实验教学管理系统（lab2026）的「实验列表」页提供筛选、余量高亮与课表冲突检测。只读增强，不会自动提交任何预约请求。

## 安装（Chrome / Edge）

1. 打开浏览器，地址栏进入 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本 `extension` 文件夹
4. 登录实验系统，进入 `学生 → 实验列表` 页面，表格上方会出现「实验选课助手」面板

## 设置课表（冲突检测的前提）

点面板右上角「课表设置」，两种方式任选：

- **粘贴解析**：用浏览器打开课表 PDF → `Ctrl+A` 全选 → `Ctrl+C` → 粘贴到文本框 → 「解析并加入」。解析出的条目需要你手动补选「星期」（PDF 复制文本里没有星期信息）
- **手动点选**：直接在周网格上点亮有课的格子（默认 1-20 周，可在列表中修改周次）

设置即时自动保存。也可用「导出 / 导入」备份课表 JSON。

## 列表页功能

- 关键字搜索：实验名 / 教师 / 地点
- 按星期、场次点选筛选（chip 标签显示场次时间，如「第2场 10:20」，悬停看完整时段）
- 仅看可约 / 隐藏已满 / 隐藏冲突场次
- 剩余人数多优先排序
- 课表冲突的场次整行标红并注明冲突课程
- 筛选条件自动记忆，下次进入页面保持不变

## 实验时间表与冲突检测

实验中心的官方上课时间与理论课节次**不完全对应**（尤其晚场），因此冲突检测按**真实时间重叠**判定，而非简单比较节组编号。

### 实验场次时间（官方）

| 2学时 | 时间 | 4学时 | 时间 |
|-------|------|-------|------|
| 第1场 | 08:20–09:50 | 第1场 | 08:20–11:20 |
| 第2场 | 10:20–11:50 | 第2场 | 14:00–17:00 |
| 第3场 | 14:00–15:30 | 第3场 | 17:45–20:45 |
| 第4场 | 16:00–17:30 | | |
| 第5场 | 17:45–19:15 | | |

### 理论课节次时间（12节制）

| 节次 | 时间 | 节次 | 时间 |
|------|------|------|------|
| 1节 | 08:20–09:05 | 7节 | 16:00–16:45 |
| 2节 | 09:10–09:55 | 8节 | 16:50–17:35 |
| 3节 | 10:20–11:05 | 9节 | 18:30–19:15 |
| 4节 | 11:10–11:55 | 10节 | 19:20–20:05 |
| 5节 | 14:00–14:45 | 11节 | 20:30–21:20 |
| 6节 | 14:50–15:35 | 12节 | 21:25–22:00 |

### 关键差异

- **晚场**：实验第5场 17:45–19:15 vs 理论晚9节起 18:30–22:00，相差 45 分钟
- **4学时晚场**：实验只有一场 17:45–20:45，不是两个节组
- 粘贴课表时若课程含晚9-10节（`slotSpan=[9,10]`→18:30–20:05），与实验第5场有 45 分钟重叠→判冲突；若为11-12节（20:30–22:00）则不重叠→不冲突
- 重叠 ≥ 10 分钟才计为冲突，避免边界擦边误报

## 文件结构

```
extension/
├── manifest.json   # MV3 配置，仅声明 storage 权限
├── shared.js       # 纯函数：节次码解析 / 课表文本解析 / 冲突检测
├── content.js      # 注入实验列表页与我的实验页
├── panel.css       # 面板与标记样式
├── options.html/js/css  # 课表设置页
└── icons/          # 图标
```
